The Chain Race Dashboard is VAG's central command view for the Virtuals economy. It watches Robinhood Chain and Base simultaneously — block by block — and surfaces every signal that matters: capital inflow, total value locked, DEX volume, token launches, fees, and more. Everything on this page refreshes continuously so you always see where momentum is right now, not where it was an hour ago.

## What the Page Color Means

The background of the dashboard shifts color based on which chain is pulling more net inflow today. When Robinhood Chain is leading, the page takes on Robinhood's brand hue; when Base is ahead, it shifts to Base's. This is the fastest possible signal — you know at a glance which chain is winning capital today before you read a single number.

<Info>
  The color is driven by the **Net Inflow 24h** figure (TVL delta proxy). It updates continuously as on-chain data flows in.
</Info>

## The Headline Ticker

Six live stats run across the top of the dashboard. Here is what each one means:

| Stat | What it measures | Source |
|---|---|---|
| **Launches 24h** | New token launches via Virtuals Protocol on Robinhood Chain in the last 24 hours | api.virtuals.io |
| **Chain TVL** | Total value locked in DeFi protocols across Robinhood Chain | DefiLlama |
| **Net Inflow 24h** | 24-hour change in TVL — a proxy for net capital flowing into the chain | DefiLlama (TVL delta) |
| **DEX Vol 24h** | Total decentralized exchange trading volume on Robinhood Chain in the last 24 hours | DefiLlama |
| **Stablecoins** | Total stablecoin supply bridged or minted on Robinhood Chain | growthepie |
| **VIRTUAL** | Live spot price of the VIRTUAL governance token | Market data feed |

The percentage labels next to each figure show the change over the most recent comparable window (e.g., **+15.4% 7d** next to Chain TVL, **-36.3% 1d** next to DEX vol). Negative percentages are styled in red; positive in green.

### 3. Macro Charts

Below the table, four 90-day historical charts let you zoom out from the real-time race and see how each chain's fundamentals have trended over time:

| Chart | What it shows |
|---|---|
| **Value Secured** | L2Beat Total Value Secured (TVS) — assets locked in the chain's bridge contracts |
| **DeFi TVL** | DefiLlama aggregate TVL across all DeFi protocols on each chain |
| **DEX Volume** | Daily DEX trading volume from DefiLlama, smoothed to daily closes |
| **Stablecoin Supply** | Stablecoin balances on each chain from growthepie, with a one-day reporting lag |

Each chart overlays both chains so you can see crossover points, divergence, and relative growth trajectories at a glance.
