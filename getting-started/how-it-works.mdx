This page explains what VAG monitors, where its data comes from, how live updates work, and which features are available to everyone versus which require a Premium subscription.

## Data Sources

VAG pulls from a carefully selected set of public and on-chain data providers to ensure accuracy and depth across every metric.

| Source | What It Provides |
|---|---|
| **L2Beat** | Layer 2 security metrics, value secured, and chain risk assessments for Robinhood Chain and Base |
| **DefiLlama** | Chain TVL, protocol-level liquidity, DEX volumes, and stablecoin data |
| **growthepie** | Cross-chain activity metrics, fee data, and ecosystem growth analytics (~1-day data lag) |
| **api.virtuals.io** | Live launch data, token metadata, and launchpad activity from the Virtuals Protocol ecosystem |
| **Blockscout** | Block-level on-chain data, transaction activity, and contract analytics |
| **Yahoo Finance** | Reference pricing and financial data for tokenized real-world assets and their underlying equities |
| **SEC EDGAR** | Official regulatory filings and disclosures relevant to tokenized stocks and RWA issuers |

## How Live Updates Work

VAG refreshes its core metrics continuously as new blocks are confirmed on Robinhood Chain and Base. Here is what to expect for each data type:

- **Chain metrics** (TVL, net inflow, DEX volume, stablecoins, VIRTUAL price) — updated in real time, block by block
- **Launch feed** — new token launches appear as soon as they are detected on-chain
- **Tokenized stock prices** — live prices are available to Premium (Basic and above) subscribers
- **RWA news feed** — refreshed every 15 minutes from external sources
- **growthepie analytics** — carries approximately a 1-day lag due to upstream data processing; use these figures for trend analysis rather than real-time decisions

### Free for Everyone

- **Chain race metrics** — TVL, net inflow, DEX volume, stablecoins, and fees across both chains

- **Stock token directory** — full list of tokenized RWAs with basic info
